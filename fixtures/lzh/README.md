LZH test archives from the lhasa project (https://github.com/fragglet/lhasa, ISC licence,
`LICENSE-lhasa-ISC.md`), as copied into rust-delharc's tests. The prefix names the tool that
wrote each archive: `lha_unix114i` (LHA for Unix 1.14i), `explzh_723` (ExpLZH 7.23, Windows),
`unlha32` (UNLHA32.DLL 2.67a). `gpl-2` inside is the GPL v2 text (18092 bytes).
