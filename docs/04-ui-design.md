# 04 · 界面与交互设计

## 1. 设计原则

1. **大气来自留白与层级，而非装饰。** 8pt 网格，少用分割线，多用面（surface）与间距分组。
2. **内容优先。** 文件列表是舞台，工具栏、侧栏是舞台的边框，视觉权重必须低于内容。
3. **最常见任务一步到位。** 右键解压、拖放压缩、Enter 进入目录，都不需要第二步。
4. **原生感 + 一致性。** 标题栏、字体、滚动条、快捷键遵从各平台习惯；其余视觉完全一致。
5. **克制动效。** 150–220 ms、ease-out；尊重 `prefers-reduced-motion`。
6. **可访问是基础能力。** 键盘全覆盖、对比度 ≥ AA、屏幕阅读器可用。

## 2. 视觉语言

| 要素 | 规范 |
|---|---|
| 字体 | Windows：Segoe UI Variable → 微软雅黑；macOS：SF Pro（`-apple-system`）→ 苹方；Linux：Inter → Noto Sans → Noto Sans CJK SC；等宽：Cascadia Code / SF Mono / JetBrains Mono |
| 字号阶梯 | 11 / 12 / 13 / **14（基准）** / 16 / 20 / 28；行高 1.45 |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32 / 48 |
| 圆角 | 4（控件）/ 8（卡片、输入）/ 12（浮层、对话框）；窗口圆角随平台 |
| 阴影 | 仅浮层使用，两级（menu / dialog） |
| 色彩 | 中性灰阶 + **单一强调色**；语义色 success / warning / danger / info；文件图标提供克制的类型色 |
| 材质 | Win11：侧栏 Mica，内容区不透明；macOS：侧栏 vibrancy；Linux：纯色 |
| 图标 | Lucide 线性图标 1.5 px；文件类型图标集提供"单色"与"双色"两套，随主题切换 |
| 密度 | 紧凑（行高 28）/ 舒适（32，默认）/ 宽松（40） |

区域说明：

| 区域 | 行为 |
|---|---|
| 标题栏 | Windows / Linux 自绘（含窗口控制按钮、Snap Layout 悬停）。Linux 窗口同样去掉系统边框（`decorations: false`），四周一道 1 px 细线标出窗口边界（系统不给无边框窗口画阴影）；网页视图会先拿走鼠标，窗口自身收不到边框上的按下，因此页面四边与四角各有 5–8 px 的透明区域，按下即交给窗口管理器调整大小（`startResizeDragging`），最大化时去掉；macOS 使用 overlay 风格保留原生红黄绿按钮，垂直居中于侧栏顶行（与折叠按钮同一行），Logo、名称与版本号移到其下一行；标题与 Windows 一样靠左。中央显示当前压缩包名，可点击弹出"最近"。中间为搜索框（浏览压缩包时）；右侧：主题菜单（浅色 / 深色 / 跟随系统，以及当前明暗下的主题）、界面语言菜单（设置入口在侧栏底部） |
| 侧栏 | 可折叠为 48 px 图标栏。上部为固定入口，中部为已打开的压缩包（可同时打开多个，每个一行，带格式与关闭按钮；点击切换，各自记住所在目录、历史、选择与搜索；每个压缩包前有箭头，可各自展开 / 收起目录树，可同时展开多个；新打开或切换到的压缩包自动展开，展开状态按路径记忆，压缩包改写后不变；当前压缩包名称加粗；点击其他压缩包目录树中的文件夹即切换过去并进入该文件夹；再次打开已打开的压缩包时切换过去；关闭当前压缩包后显示相邻的），底部为"已挂载"列表（含弹出按钮）、任务摘要与"设置"（设置分组向上展开，见 §4.9）。宽度可拖动并记忆 |
| 命令栏 | 上下文相关：未选中 → 添加 / 解压全部 / 挂载 / 测试；选中 → 解压所选 / 删除 / 重命名 / 属性。溢出项进入"···" |
| 面包屑 | 每段可点击；支持粘贴路径跳转；嵌套压缩包显示为层叠段 |
| 列表 | 虚拟化表格 / 网格两种视图；列可拖动排序、显隐、宽度记忆；行内显示加密、损坏、符号链接徽标 |
| 状态栏 | 仅在浏览压缩包时显示。左：格式徽章与关键属性；中：计数与选择；右：压缩率。悬停显示详细信息（应用版本号显示在侧栏顶部的名称旁） |

```
│          └──────────────────────────────────┘            │
│                                                          │
│     [ 打开压缩包 ]   [ 新建压缩包 ]   [ 解压到… ]          │
│                                                          │
│   最近                                              清除 │
│   ┌────────────┐ ┌────────────┐ ┌────────────┐           │
│   │ 7z  backup  │ │ zip photos │ │ rar movie  │  …        │
│   │ 2.1 GB 今天 │ │ 480 MB 昨天│ │ 1.4 GB 周一│           │
```

- 拖放智能判定：全部为压缩包 → 打开（多个则询问"分别打开 / 批量解压"）；含非压缩包 → 进入"新建压缩包"并预填。
- 最近项卡片右键：打开所在位置、从列表移除、固定。

### 4.2 新建压缩包（对话框）

开始页的"新建压缩包"先打开一个空的新压缩包，像已打开的压缩包一样浏览：拖入或"添加文件 / 添加文件夹"放入内容，可"新建文件夹"、重命名、删除，整理好后"保存…"（Ctrl+S）弹出下面的对话框选择格式、密码与保存位置；保存成功后自动打开生成的压缩包。新压缩包只在内存中记录每一项在压缩包中的位置与来源文件，编辑即时生效，不产生任务；未保存而要打开其他压缩包或关闭时先确认放弃。拖到开始页的非压缩文件同样进入一个新压缩包。"压缩文件夹"与右键"添加到压缩包…"仍直接打开对话框，一步压缩。它与解压、挂载、转换一样是居中的对话框（原为右侧滑出的面板，2026-10-30 统一）；右键菜单打开时是同一对话框的独立小窗（07 §2）。

```
┌─ 新建压缩包 ───────────────────────────────────────── ✕ ─┐
│  保存为  D:\Downloads\project.7z                          │
│  [ project                              ] .7z  [浏览…]   │
│                                                            │
│  格式          压缩级别 · 标准                              │
│  [ 7Z    ▾ ]   存储 ─────●───── 极限                        │
│  预设      [ 默认 ▾ ]                      [保存为预设]     │
│                                                            │
│  ▾ 高级   已加密 · 分卷 FAT32（4 GiB）                       │
│    加密 •   分卷 •   方法    其他                           │
│    ━━━━━━──────────────────────────────────────────         │
│    密码  [ ••••••••••      👁 ]  强度 ▰▰▰▱                  │
│          ☑ 同时加密文件名（7z）                             │
│                                                            │
│  ☐ 完成后删除源文件    ☑ 完成后校验    ☐ 完成后打开所在位置 │
│                                                            │
│  86 个文件 · 1.2 GB → 约 410 MB · 45秒 [ 取消 ] [ 开始压缩 ] │
└────────────────────────────────────────────────────────────┘
```

- 格式切换时，仅显示该格式支持的选项（能力驱动）。
- 完整保存路径跟在"保存为"标签后；过长时省略开头，文件名始终可见。
- 文件数、原始大小、预计压缩后大小与耗时合为一行（如"182 个文件 · 1.53 GB → 约 861 MB · 14秒"），放在底部按钮行左侧，随格式和级别变化，展开高级区滚动时也一直可见。
- 密码输入框旁可选"从已保存密码选择"（钥匙串）。
- 高级区分标签页：加密（密码、加密文件名）、分卷、方法（方法、固实、跳过已压缩的文件；格式无可选方法时不显示）、其他（注释、排除规则）。各页叠放在同一区域、高度取最高者，切换标签页时窗口大小不变；收起时标题后显示已生效的加密与分卷，否则显示各项名称。标签页是文字加下划线（当前页下划线为强调色），与选值用的分段控件区分开；设置了非默认值的标签页带圆点（密码、分卷、方法或关闭固实或与设置不同的"跳过已压缩的文件"、注释或排除规则）；左右键切换。
- 高级区折叠记忆用户上次状态。

### 4.3 解压对话框

```
┌─ 解压 photos-2026.zip ──────────────────────────── ✕ ─┐
│  解压到                                                 │
│  [ D:\Downloads\photos-2026\               ▾ ] [浏览] │
│  路径                         已有文件                  │
│  [ 智能                ▾ ]    [ 询问                ▾ ] │
│  ▸ 更多  密码 · 文件名编码 · 损坏文件                    │
│  ☑ 完成后打开目标文件夹   ☐ 完成后将压缩包移到回收站      │
│                                  [ 取消 ]  [ 解压 ]     │
└─────────────────────────────────────────────────────────┘
```

- 目标路径下拉包含：压缩包所在目录、下载、桌面（最近使用的目录待接入）。位于盘符根目录的压缩包默认目标为 `D:\`，不写成含义不同的 `D:`。
- "路径"（智能 / 保留目录 / 不保留目录）与"已有文件"（询问 / 跳过 / 覆盖 / 仅覆盖较旧 / 保留两者）为并排的两个下拉框。
- 密码默认收在"更多"里：未填写密码而压缩包需要时，任务会弹出密码对话框（§4.7），在同一窗口内完成。
- 批量解压多个压缩包时显示"每个压缩包解压到独立文件夹"开关（默认开）。
- 从文件管理器"解压到…"打开时，对话框是一个独立小窗（不打开主窗口），点"解压"后同一窗口转为轻量进度窗（§4.4，见 07 §2）。

### 4.4 轻量进度窗（Shell 触发的操作）

从右键菜单"解压到此处"等入口触发时，不打开主窗口，只显示一个小窗：

```
┌─ 正在解压 photos-2026.zip ───────────────────┐
│  ▰▰▰▰▰▰▰▰▰▰▰▰▱▱▱▱▱▱  64%   128 MB/s   剩余 12 秒 │
│  IMG_2041.jpg                                 │
│                    [ 后台 ] [ 暂停 ] [ 取消 ]  │
└───────────────────────────────────────────────┘
```

- "后台"收起到托盘 / 菜单栏图标，完成后系统通知。
- 任务栏（Windows `ITaskbarList3`）/ Dock 显示进度。
- 出错或需要密码时窗口置顶并扩展为对应对话框。

### 4.5 任务中心

- 侧栏底部摘要（任务数 + 总进度）；点击展开为右侧抽屉。
- 每个任务：图标、名称、进度条、速度、剩余时间、当前文件；操作：暂停（v1.1）、取消、完成后打开位置、查看日志。
- 失败任务保留错误详情，可"重试"或"跳过错误继续"。

### 4.6 冲突对话框

并排显示"已存在 / 压缩包内"两个文件的大小、修改时间、缩略图（图片）；按钮：覆盖、跳过、保留两者（自动重命名）、仅覆盖较旧；复选"对剩余冲突应用相同操作"。

### 4.7 密码对话框

掩码切换、"记住本次会话"、"尝试已保存的密码"（按成功率排序）；连续失败 3 次提示检查编码/大小写。

### 4.8 预览窗口

独立窗口，标签页式。左右键切换同目录相邻文件（图片浏览心智）。支持文本（高亮）、图片（缩放 / 旋转 / EXIF）、PDF、十六进制、音视频（系统解码可用时）。底部显示路径、大小、CRC。

### 4.9 设置

设置分组列在侧栏：点击底部的"设置"后，分组列表在它上方向上展开，再次点击收起并回到之前的页面；窄窗口（侧栏收进抽屉）时分组改为显示在设置页顶部。

| 分组 | 内容 |
|---|---|
| 常规 | 启动页、默认解压位置策略、关闭行为、通知、回收站/永久删除；压缩对话框的默认值（新建压缩包的格式、压缩级别、跳过已压缩的文件，03 §6.1）、预设管理 |
| 外观 | 模式（浅色 / 深色 / 跟随系统）、主题选择与预览、强调色、窗口材质、密度、图标风格、字体缩放 |
| 语言 | 界面语言（日期与数字格式随之）、文件大小单位（KB / KiB）、默认文件名编码 |
| 文件关联 | 设为默认压缩软件（在最上方）、各格式的支持程度与"用 OmniZip 打开"勾选表（按平台实现） |
| 右键菜单与集成 | 菜单样式（级联 / 平铺）、显示哪些项、图标开关、CLI 加入 PATH、补全安装 |
| 安全 | 压缩炸弹阈值、MOTW、符号链接策略、密码保存到钥匙串 |
| 挂载 | 后端状态与安装引导（WinFsp / FSKit / FUSE）、默认挂载位置、缓存上限与清理、退出时自动卸载、启动时恢复、固实包预热、离线属性 |
| 高级 | 线程数、缓存目录、日志级别、诊断导出、实验性功能 |
| 关于 | 版本、更新渠道、开源许可、第三方组件 |

### 4.10 挂载（把压缩包当磁盘用）

点击命令栏"挂载"默认一键完成并在文件管理器中打开；按住 Alt 点击或从下拉箭头打开选项面板：

```
┌─ 挂载 photos-2026.zip ───────────────────────────── ✕ ─┐
│  挂载为   (●) 盘符 [ Z: ▾ ]   ( ) 文件夹 [            ] │
│  卷标     [ photos-2026                              ] │
│  访问     (●) 只读   ( ) 可写（ZIP，卸载时保存）        │
│  ☑ 退出 OmniZip 后保持挂载     ☐ 后台预热（固实包）     │
│  ▸ 更多   缓存上限 · 离线属性 · 文件名编码               │
│  ⓘ 此压缩包为 Deflate ZIP，随机访问良好                  │
│                                   [ 取消 ]  [ 挂载 ]    │
└─────────────────────────────────────────────────────────┘
```

- 面板顶部信息行根据格式的挂载等级（见 03 §10）给出体验提示；固实包显示预计首次访问时间。
- 挂载成功：侧栏"已挂载"新增一行（名称、挂载点、缓存占用、⏏ 弹出），状态栏出现挂载徽标，toast 提供"打开"。
- 卸载：侧栏 ⏏、右键菜单、托盘菜单、或系统原生弹出；有文件被占用时提示占用进程（Windows 通过 Restart Manager 查询）并可"强制卸载"。
- 挂载管理页（设置 → 挂载）与侧栏同源，显示后端健康状态。
- 文件管理器右键"挂载"：只弹出此面板的独立小窗（07 §2），不打开主窗口；格式与挂载等级直接从文件判断，不列举压缩包内容（tar.gz 等单流压缩包无需先解压一遍），加密的压缩包一开始就显示密码栏。

```
│  转换为          压缩级别 · 标准                         │

│                  仅存储 … 极限                            │
│  ☑ 完成后校验                                           │

└─────────────────────────────────────────────────────────┘
```

- 新压缩包与原压缩包同名、扩展名换成目标格式，默认保存在原压缩包所在文件夹；单个压缩包显示完整路径，多个时显示数量。同名文件已存在时提示将被替换；与本次要转换的某个压缩包（例如同格式、同文件夹）或另一个新压缩包重名时依次改名为"名称 (2).扩展名"等，从不覆盖要读取的压缩包（后端也会拒绝这样的请求）。
- 目标格式只列可容纳多个条目的可写格式（ZIP、7z、tar 及其压缩组合）；默认取设置中的默认格式，与原格式相同时改用 7z（原为 7z 时用 ZIP）。压缩级别默认取设置。
- 转换先把内容解压到新压缩包旁的临时文件夹，再写出新压缩包（`omnizip_formats::convert`）；原压缩包需要密码时由任务弹出密码对话框。"完成后校验"测试新压缩包，失败则报错并保留原压缩包；有条目未能转换（警告）时也不删除原压缩包。
- 从文件管理器打开时与"解压到…"相同：对话框是独立小窗，开始后转为轻量进度窗（§4.4）。

## 5. 交互细节

### 5.1 快捷键（Windows / Linux，macOS 用 ⌘ 替换 Ctrl）

| 操作 | 快捷键 |
|---|---|
| 打开压缩包 / 新建 | Ctrl+O / Ctrl+N |
| 解压所选 / 全部 | Ctrl+E / Ctrl+Shift+E |
| 添加文件 | Ctrl+I（或拖入） |
| 测试 | Ctrl+T |
| 挂载 / 卸载 | Ctrl+M / Ctrl+Shift+M |
| 复制 / 剪切 / 粘贴 | Ctrl+C / Ctrl+X / Ctrl+V |
| 删除所选条目 | Delete |
| 重命名（ZIP） | F2 |
| 属性 | Alt+Enter |
| 搜索 | Ctrl+F |
| 进入目录 / 返回上级 | Enter / Backspace |
| 预览 | Space（macOS 心智，全平台一致） |
| 切换视图 | Ctrl+1 / Ctrl+2 |
| 切换主题明暗 | Ctrl+Shift+D |
| 设置 | Ctrl+, |

复制、剪切与粘贴（输入框内或选中了文字时仍是文字的复制粘贴）：

- 压缩包 → 文件管理器：Ctrl+C / Ctrl+X 时先把所选解压到缓存下的临时目录（任务中心显示"复制到剪贴板"，与普通解压相同的安全设置），完成后作为文件放到系统剪贴板，可在资源管理器、桌面或任何接收文件的程序中粘贴；按下时先清空剪贴板，解压完成前别处没有可粘贴的内容。剪切的项在列表中变淡；粘贴方把解压出的文件移走后（资源管理器粘贴剪切内容会移动文件并清空剪贴板），这些项从压缩包中删除。只读格式只能复制（剪切会提示并改为复制）。
- 压缩包 → 压缩包（含同一压缩包的其他文件夹）：粘贴到当前文件夹，复制或移动，规则同拖放；剪切只能粘贴一次。
- 文件管理器 → 压缩包：复制的文件添加到当前文件夹；剪切的文件添加成功后移入回收站并清空剪贴板。新建压缩包引用原文件，因此剪切进来的文件保持原位。
- 临时目录在下次复制时清理；启动时清理除剪贴板上仍在用的以外的旧目录。macOS / Linux 暂不接入系统剪贴板，只在应用内的压缩包之间复制粘贴。

### 5.2 拖放规则

| 来源 → 目标 | 行为 |
|---|---|
| 文件管理器 → 开始页 | 压缩包：打开；其他：新建压缩包 |
| 文件管理器 → 浏览器列表 | 添加到当前目录（仅 UPDATE 能力格式；否则提示转换） |
| 列表 → 窗口外（桌面、资源管理器等任何接收文件的位置） | 解压所选到放置位置（Windows；macOS / Linux 待做）。拖出窗口时界面内拖动转为系统拖放（原生 drag source，指针旁仍是同样的标签，目标在其下方显示"复制到 …"），同时开始把所选解压到缓存下的临时目录（与普通解压相同的安全设置：符号链接策略、来源标记）；在接收文件的目标上松开时等解压完成再交给目标复制，松在不接收的位置、本窗口上或按 Esc 则取消解压并删除临时目录。拖动中无法询问，密码未知的加密项会失败并提示。放下的临时文件留待一小时后清理（目标可能仍在后台复制） |
| 列表 → 列表内目录、面包屑、侧栏目录树、侧栏中其他已打开的压缩包及其目录树 | 移动到该文件夹，按住 Ctrl 为复制（可放入的只有 ZIP 与未保存的新压缩包；只读格式中的项只能复制出去）。同一压缩包内移动只改名，其余经临时目录解出再添加，移动时随后从来源删除；放入新压缩包的临时文件保留到它关闭。拖动时指针旁显示"移动 / 复制 N 项"（随 Ctrl 即时切换），目标高亮，Esc 取消；目标中已有同名项或把文件夹放进自身时报错。界面内拖动用指针事件实现：Windows 上 WebView 接管了拖放（接收文件管理器拖入的文件），HTML5 拖放事件不会到达页面。压缩包改写后节点重新编号，浏览器按路径找回当前文件夹并清空选择 |
| 压缩包 → 侧栏"最近" | 固定 |

### 5.3 双击与打开

- 目录：进入。
- 压缩包（嵌套）：进入子压缩包。
- 文件：按设置"预览 / 用系统程序打开 / 询问"。用系统程序打开后监视修改并提示更新。

### 5.4 多选与批量

Shift / Ctrl 多选；Ctrl+A 全选；类型筛选器（图片 / 文档 / 代码）；选中后状态栏显示合计大小。

鼠标框选：从空白处拖动画出选框（列表视图里从行内图标与名称以外的地方拖动也是框选，与资源管理器的详细信息视图一致；从图标或名称拖动仍是拖动项目），框碰到的项随拖动即时选中；按住 Ctrl 为反选这些项，按住 Shift 为加入已选；指针靠近列表上下边缘时自动滚动，继续框选。单击空白处清除选择。多个压缩包批量操作（解压、测试、转换）在任务中心逐个展示。

### 5.5 通知与反馈

- 操作成功：窗口内 toast（3 s）+ 可选系统通知（窗口不在前台时）。
- 操作失败：toast 持久化，带"查看详情"。
- 长任务完成且应用在后台：系统通知带"打开文件夹"动作。

## 6. 响应式与窄窗

- 最小窗口 720 × 480。
- 宽度 < 960：侧栏自动折叠为图标栏；列隐藏优先级：类型 → 压缩后 → 修改时间。
- 宽度 < 800：命令栏文字隐藏仅留图标，溢出到"···"。

## 7. 可访问性

- 所有控件可 Tab 到达，列表支持方向键 / Home / End / 输入首字母定位。
- Radix 提供的 ARIA 角色；自定义列表使用 `role="grid"`。
- 文本对比度 ≥ 4.5:1，图标 ≥ 3:1；高对比主题下禁用半透明与材质。
- 支持系统字体缩放（100%–200%），布局不溢出。
- `prefers-reduced-motion` 下禁用所有非必要动画。
- 屏幕阅读器播报进度（`aria-live="polite"`，节流 5 s）。

## 8. 状态与文案

| 状态 | 设计 |
|---|---|
| 加载中 | 骨架屏（列表 8 行），> 300 ms 才显示，避免闪烁 |
| 空目录 | 居中淡色图标 + "此目录为空" |
| 搜索无结果 | "没有匹配 "xxx" 的项目" + 清除搜索按钮 |
| 损坏压缩包 | 顶部横幅：可部分读取时允许继续，提供"尝试修复 / 保留损坏文件" |
| 需要密码 | 列表显示但大小/名称可见（头未加密时），解压时弹窗 |
| 缺少依赖（libarchive） | 格式灰显，提示安装方式 |

文案原则：动词开头、不出现技术缩写（除非用户选择了"高级"）、错误信息包含"发生了什么 + 可以做什么"。

## 9. 平台差异

| 平台 | 差异点 |
|---|---|
| Windows | 自绘标题栏 + Mica；窗口按钮在右；Snap Layout 悬停菜单（处理 `WM_NCHITTEST` 返回 `HTMAXBUTTON`）；任务栏进度与 Jump List（最近压缩包）；高 DPI 混合缩放 |
